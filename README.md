# Orbit & Collision Lab

Course exercise by **Zichen Yang**, HKU student, for **STEM Education**.

A self-contained STEM physics interaction page built with vanilla HTML, CSS, and JavaScript Canvas.

- Orbital gravity: explore the relationship between central mass and orbital speed
- Elastic collisions: observe momentum exchange and elasticity
- Free throw: explore velocity, gravity, and parabolic motion
- Adjustable gravity, elasticity, time scale, and motion trails
- Press and drag on the canvas to create a ball with initial velocity

## Usage

Open `index.html` directly. No dependencies or server are required.
